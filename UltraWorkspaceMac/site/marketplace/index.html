Submit an app

Phase 1: a pull request.

  1. Build a bar app.Any Android app with a launcher activity shows up on the bar. The simplest kind is a kiosk WebView that opens a page your Mac serves, which is how Deckhand's own apps work; the Android project is in the repository as a template; see build your own.
  2. Add an entry to registry.json.Id, name, package, version, a one-line summary, an icon, a screenshot at 1424 × 280 and a link to the source. Keep the shape of the existing entries.
  3. Open a pull request.Apps are reviewed for what they do on the bar and on the network before they are listed. Nothing in the index may need an account or send data off the LAN without saying so.
{
  "id": "my-app",
  "name": "My app",
  "kind": "bar-app",
  "package": "com.example.myapp",
  "version": "1.0",
  "summary": "One line on what it shows.",
  "icon": "https://example.com/icon.png",
  "screenshot": "https://example.com/bar.png",
  "requires": { "deckhand": ">=0.1", "wifiAdb": true },
  "source": "https://github.com/example/my-app",
  "distribution": "apk",
  "apk": "https://github.com/example/my-app/releases/latest/download/my-app.apk",
  "publisher": "Example",
  "license": "MIT"
}
