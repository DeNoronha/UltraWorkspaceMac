# Fluent Emoji 3D assets

The launcher-icon glyphs of the Deckhand bar apps (every flavor except `claude`) are 3D renders from Microsoft's [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) set, used under the MIT licence reproduced below. `tools/make-icons.swift` composites them on the flavor's gradient. Each file was downloaded unmodified from the `main` branch of that repository.
